# Datasets

Candidate quantitative sources for testing network claims. None have been downloaded or analyzed here.

| Dataset | What it offers | Use in this project |
|---|---|---|
| General Social Survey (US) | Core discussion network items, 1985 and 2004 | H1: network size, by sex and time |
| American Time Use Survey | Time spent with friends/family by sex | H1, `05` |
| World Values Survey | Cross-national attitudes and associational membership | Cross-cultural |
| Demographic and Health Surveys | Women's decision-making, mobility, IPV, group membership | H2, H6 |
| UNODC Global Study on Homicide | Femicide and homicide by sex/perpetrator | `09` |
| WHO violence prevalence estimates | IPV prevalence | `09` |
| Standard Cross-Cultural Sample / D-PLACE / Ethnographic Atlas | Residence, descent, subsistence, women's status | `05`, `06` |
| Seshat / historical databases | Longer-run comparison | Optional |
| Pew, Gallup surveys on loneliness and friendship | Contemporary trends | H1 |
| Bonobo long-term field datasets | Coalition, rank, sexual behavior | `01`–`03` |

Pre-registration idea: before analyzing anything, write down what result would count against each hypothesis (see falsification criteria in `hypotheses/core-hypotheses.md`).
